Cooking

A personal cooking advisor and recipe library. Persistent context, ingredient intelligence, and a structured place for everything worth keeping.

Why This Exists

Most recipe apps are optimized for discovery, not memory. They don't know you already make a great tonkatsu, that you have rosemary in the garden right now, that you hate anything that reads as "too French," or that it's Tuesday night and you have 40 minutes.

This system does. It holds your full cooking profile — preferences, pantry, trusted sources, past experiments — and reasons from it. The goal is an advisor that knows your kitchen as well as you do.

What This Is

Claude Code loads CLAUDE.md at session start. Combined with structured context files and the Epicure ingredient embedding model (wired in as a live MCP server), each session has:

  • Your full cooking profile — household, style, cuisines, techniques, dislikes
  • Current pantry and garden state
  • Trusted technique sources (Kenji, Hazan, ATK, McFadden, Mallmann)
  • Ingredient intelligence — flavor neighbors, pairing scores, cultural affinities
  • A growing recipe library and log of past sessions

Epicure Ingredient Intelligence

The Epicure model embeds 1,790 ingredients as 300-dimensional vectors trained on 4.14M recipes. Claude has access to it as a live MCP server and uses it automatically — you don't invoke it manually.

ToolWhen Claude uses it
neighborsSubstitution questions — finds closest flavor neighbors
find_pairings"What goes with X?" — cluster and bridge graph
pairing_scoreChecking affinity between two specific ingredients
cultural_profileWhich cuisine an ingredient fits best
compare_on_axisComparing two ingredients on a named flavor axis
morphExploring a flavor direction from a starting ingredient
The epicure-mcp server must be running before a session. Run bin/epicure in a terminal, or install the launchd plist to auto-start it at login.

How to Use It

Weeknight question

Open a Claude Code session in /cooking. Ask something. The advisor knows your profile, your pantry, and your time constraints. It will give a specific recommendation — not "it depends."

Saving a recipe

Tell Claude to save it: "save this as a recipe." It creates recipes/YYYY-MM-DD-name.md with what you made, the source, and any notes.

Logging a session

After an experiment, log what happened: "log tonight — I made X, changed Y, result was Z." Claude writes it to log/YYYY/MM-DD.md and updates the wiki if there's a pattern worth noting.

The Wiki Layer

The wiki/ directory is compiled synthesis — Claude maintains it, you don't write to it directly. Raw notes go in log/. The wiki is where patterns become visible: flavor combinations that keep working, seasonal observations, cross-cuisine moves that generalize.

It starts sparse and fills in over time. That's correct.
